The keyboard toolbar provides touch-friendly buttons for common terminal keys. Its bottom row holds
the keys used most; the **Extra keys** button (⋯), pinned at its right end, shows the expanded rows
with every other key.

## Bottom Row

| Button | Key / action                                        |
| ------ | --------------------------------------------------- |
| ⌨️     | Show/hide the virtual keyboard                      |
| 🌐     | Text input mode (IME) for non-Latin scripts         |
| Esc    | Escape (clears Ctrl/Shift when one is on)           |
| Ctrl   | Ctrl modifier (sticky)                              |
| ↑ ↓    | Up/Down arrows                                      |
| Enter  | Submit command                                      |
| Tab    | Autocomplete                                        |
| ⋯      | Extra keys: show or hide the expanded rows           |

When the row does not fit the screen it scrolls sideways, and the edge that still hides keys fades
out. The ⋯ button stays at the right end, outside the scrolling part, so it is always on screen.

## Expanded Rows

Tap ⋯ (or turn on **Toolbar default expanded** in [Settings](/usage/settings/)) to show labelled
rows above the bottom row:

| Row                  | Keys                                                                           |
| -------------------- | ------------------------------------------------------------------------------ |
| Actions (mobile)     | Clear, Cancel, Clear line, Exit: see [Actions row](#actions-row-mobile-only) |
| Text · Scroll        | Command history, Paste, Attach image, Select text, tmux copy mode, scroll up/down |
| Navigate             | Shift, Shift+Tab, ←, →, Home, End, PgUp, PgDn, Del, Bksp, Ins                  |

The rows close by themselves when the on-screen keyboard opens and when you open the command
history, so they never cover the whole terminal together; tap ⋯ to show them again.

While Ctrl is on, its combos float above the toolbar instead of adding a row, so the terminal keeps
its size and a running full-screen program does not redraw. Ctrl+Shift combos float the same way.

## Modifiers

| Button | Key     | Where        |
| ------ | ------- | ------------ |
| Ctrl   | Control | Bottom row   |
| Shift  | Shift   | Navigate row |

### Modifier Combinations

- **Ctrl only**: Shows Ctrl combos (^C, ^D, etc.)
- **Shift only**: Modifies next key; the **⇧Tab** key sends Shift+Tab in one tap. Closing the
  expanded rows turns Shift off, since its key is no longer on screen
- **Ctrl+Shift**: Shows Ctrl+Shift combos (^⇧C, ^⇧V, etc.)

### tmux Copy/Paste Workflow

1. Tap the **copy mode icon** to enter copy mode
2. Use arrow keys to navigate
3. Press **Space** to start selection
4. Navigate to select text
5. Press **Enter** to copy to tmux buffer
6. Tap the **Paste icon** to paste (with the paste source set to tmux buffer in [Settings](/usage/settings/))

:::note[Herdr backend]
Herdr has no tmux copy mode or paste buffer, so the copy mode key is hidden, the Select text key
takes its place, and the Paste icon always uses the system clipboard.
:::

### Copy text

The tmux workflow above copies into the tmux buffer only. To put terminal text on the device's own
clipboard:

- **Select text key** (phone and desktop, tmux and Herdr): opens a sheet with the pane's text, its
  history included (the last 1000 lines; **Load more** reads up to 5000). Select with a long press
  and the selection handles, or drag with a mouse, then tap **Copy**; **Copy all** copies everything.
  Hidden characters (bidi marks, zero-width spaces) show as `⟨U+XXXX⟩` and are copied as they are.
  On a view-only device, or where the server cannot read the history (psmux), the sheet shows what
  the terminal on the page holds, and says so.
- **Ctrl+Shift+C** (desktop, not on a Mac): with text selected by the mouse, copies it and sends
  nothing to the terminal; without a selection the keys reach the program as before. The ^⇧C toolbar
  combo does the same. On a Mac, Cmd+C copies the selection.
- **Copy on select** in [Settings](/usage/settings/): copies as soon as you release the mouse button.

A page opened over plain HTTP (a LAN address) has no Clipboard API; copying falls back to the
browser's copy command and shows an error when that is refused too. The Herdr terminal redraws its
whole screen when its stream starts again, which clears a mouse selection.

:::note[Native Mode Setup]
For native mode, add this to your `~/.tmux.conf`:
```bash
set-option -g mode-keys vi
```
Container mode has this pre-configured.
:::

## Text Input Mode (Non-Latin)

Tap the **Languages icon** to switch to text input mode. This is designed for typing non-Latin scripts (Vietnamese, Chinese, Japanese, Korean, Thai, etc.) that require IME composition.

| Action    | Result                                                                        |
| --------- | ----------------------------------------------------------------------------- |
| Type text | Compose using your device's IME                                               |
| Tap Send  | Send text to terminal (behavior configurable in [Settings](/usage/settings/)) |
| Tap ✕     | Close text input, return to key toolbar                                       |

## Touch Targets

- Minimum size: 44x44px
- Spacing: 8px between buttons
- Haptic feedback on tap (if device supports)

## Command History

Tap the **clock icon** (🕐) in the Text · Scroll row of the expanded toolbar to open the command history dropdown. View, search, and reuse previously sent commands.

### Features

| Feature           | Behavior                                                     |
| ----------------- | ------------------------------------------------------------ |
| Search bar        | Filter commands by typing                                    |
| Keyboard nav      | Use Up/Down arrows to navigate, Enter to select, Esc to exit |
| Delete button     | Remove individual commands from history                      |
| Clear all button  | Wipe entire history at once                                  |
| Delete via settings | Clear history via Settings → "Clear Command History"        |

### How It Works

- **Automatic capture**: Commands are saved when you press Send in text input mode (IME)
- **Persistence**: History saved to browser local storage
- **Per-browser**: History is device/browser-specific, not synced across devices
- **Search**: Filter by partial command name for quick access

<Aside>
Commands sent via keyboard toolbar buttons (Ctrl+C, etc.) are not added to history — only IME text submissions are captured.
</Aside>

## Actions Row (Mobile Only)

On a phone the expanded toolbar starts with an **Actions** row of common terminal actions. Tap ⋯
to show it.

| Action     | Function            | Sends           |
| ---------- | ------------------- | --------------- |
| Clear      | Clear terminal      | `clear` command |
| Cancel     | Interrupt process   | Ctrl+C          |
| Clear line | Delete current line | Ctrl+U          |
| Exit       | Logout/EOF          | Ctrl+D          |

<Aside>
The Actions row appears on mobile devices only. On desktop, use the keyboard toolbar keys instead.
</Aside>

## Attach an Image

Claude Code reads an image you paste, but only from the clipboard of the machine it runs on, which
is empty when the image is on your phone. Termote uploads the image to that machine instead and
types its path into the terminal, followed by a space; Claude Code (or Codex) turns the path into
an attachment.

- **Image key** in the Text · Scroll row of the expanded toolbar: pick a photo, or take one with the
  camera.
- **Paste**: paste an image into the terminal (Ctrl+V on desktop), or tap the Paste key, long
  press the terminal or press Ctrl+Shift+V with an image on the clipboard. When the clipboard holds
  text too, the text is pasted, not the image.

PNG, JPEG, GIF and WebP up to 10 MB are accepted. iOS normally sends a photo as JPEG; a HEIC file
is refused, share it as JPEG instead. If you switch to another pane while the image uploads,
nothing is typed: a message offers to insert the path into the pane you are on.

The images are saved on the host in the user's cache directory (`~/.cache/termote/uploads` on
Linux, `~/Library/Caches/termote/uploads` on macOS, `%LOCALAPPDATA%\termote\uploads` on
Windows), readable only by that user. They are deleted after 7 days, or sooner, oldest first,
when they take more than 200 MB. The image key is hidden when the server cannot store uploads, and
for a view-only session.

## Tips

1. **Modifiers are sticky**: Tap Ctrl or Shift once, then tap another key
2. **Combine modifiers**: Tap both Ctrl and Shift for Ctrl+Shift combos
3. **Shift+Tab**: The ⇧Tab key navigates backwards in completion/menus
4. **Copy mode** (tmux): Enable to select text, disable to resume typing; to copy to the device,
   use [Select text](#copy-text)
5. **Extra keys**: Tap ⋯ for the expanded rows with Shift, Home, End, etc.
6. **Command history**: Use 🕐 clock icon to quickly reuse previous commands
7. **Actions**: On a phone, the Actions row has Clear, Cancel, Clear line and Exit
