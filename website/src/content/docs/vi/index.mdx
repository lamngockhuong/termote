Termote là ứng dụng web mã nguồn mở (MIT), tự host, đưa các phiên terminal trên máy của bạn lên điện thoại hoặc một
máy tính khác. Chỉ một file `termote` chạy trên Linux, macOS hoặc Windows, phục vụ một PWA mở các phiên tmux, Herdr
hoặc Zellij (Linux, macOS) qua mạng bạn chọn: mạng LAN, Tailscale hoặc Cloudflare Tunnel, có mật khẩu bảo vệ. Từ đó bạn có thể
[trả lời Claude Code hoặc Codex như chat](/vi/usage/agent-chat/), [chuyển phiên](/vi/usage/sessions/), xem
[file và diff git](/vi/usage/files-changes/) của pane, và gõ bằng [thanh phím](/vi/usage/keyboard/) dành cho màn hình
cảm ứng. Phần [mô hình bảo mật](/vi/usage/security/) nói rõ những gì được mở ra mạng và cách bảo vệ.

## Cài đặt nhanh

```bash
curl -fsSL https://termote.ohnice.app/install.sh | sh      # Linux, macOS
termote start
```

```powershell
irm https://termote.ohnice.app/install.ps1 | iex           # Windows
termote start
```

## Chế độ triển khai

| Chế độ    | Lệnh                   | Trường hợp sử dụng                       | Nền tảng              |
| --------- | ---------------------- | ---------------------------------------- | --------------------- |
| Native    | `termote start`        | Truy cập công cụ trên máy (Claude Code)  | macOS, Linux, Windows |
| Container | `termote container up` | Môi trường tách biệt (Podman/Docker)     | macOS, Linux, Windows |
