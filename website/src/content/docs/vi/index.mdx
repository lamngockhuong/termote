## Cài đặt nhanh

```bash
curl -fsSL https://termote.ohnice.app/install.sh | sh      # Linux, macOS
termote start
```

```powershell
irm https://termote.ohnice.app/install.ps1 | iex           # Windows
termote start
```

## Chế độ triển khai

| Chế độ    | Lệnh                   | Trường hợp sử dụng                       | Nền tảng              |
| --------- | ---------------------- | ---------------------------------------- | --------------------- |
| Native    | `termote start`        | Truy cập công cụ trên máy (Claude Code)  | macOS, Linux, Windows |
| Container | `termote container up` | Môi trường tách biệt (Podman/Docker)     | macOS, Linux, Windows |
