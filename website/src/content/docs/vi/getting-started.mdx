Termote đưa các phiên terminal trên máy của bạn, cùng Claude Code hay Codex đang chạy trong đó, lên điện thoại hoặc
một máy tính khác. Termote chỉ là một file binary, trong đó có sẵn PWA, luồng terminal, API và phần đăng nhập. Bạn
cài nó bằng một lệnh, sau đó `termote start` đăng ký nó thành dịch vụ của người dùng hiện tại rồi khởi động.

## Yêu cầu

Cần [tmux](https://github.com/tmux/tmux) trên Linux hoặc macOS (`sudo apt install tmux`, `brew install tmux`), hoặc
[psmux](https://github.com/psmux/psmux) trên Windows (`winget install psmux`); Herdr, Zellij và herdr-core cũng dùng
được ([các backend](/vi/installation/native/#yêu-cầu)), còn [chế độ container](/vi/installation/docker/) thì cần
Podman hoặc Docker. Không cần sudo hay quyền quản trị: mọi thứ đều nằm trong thư mục home của bạn.

## Cài đặt

<Tabs>
  <TabItem label="Linux / macOS">

    ```bash
    curl -fsSL https://termote.ohnice.app/install.sh | sh
    termote start
    ```
  </TabItem>
  <TabItem label="Windows (PowerShell)">

    ```powershell
    irm https://termote.ohnice.app/install.ps1 | iex
    termote start
    ```
  </TabItem>
</Tabs>

<Steps>
1. Trình cài đặt chọn bản ổn định mới nhất (từ 1.0 trở lên), tải file nén cho nền tảng của bạn, kiểm tra `.sha256` của nó
   (luôn kiểm tra, không có cách bỏ qua) rồi đưa lệnh `termote` vào PATH. Nó không khởi động gì cả.

2. `termote start` dò tìm backend terminal, tạo mật khẩu admin và in ra một lần (chỉ khi chạy trong terminal), đăng ký server với trình quản
   lý dịch vụ của hệ điều hành rồi khởi động nó. Xem
   [`termote start` làm những gì](/vi/installation/native/#termote-start-làm-những-gì).

3. Mở URL được in ra, mặc định là http://127.0.0.1:7680 (Windows: http://127.0.0.1:7690), rồi đăng nhập bằng
   `admin` (hoặc tên đặt bằng `--user`) với mật khẩu đó. Quên mật khẩu thì chạy `termote show-password`.

</Steps>

<Aside type="tip">
  Nếu vừa cài xong mà chưa gọi được `termote`, hãy mở terminal mới. Trên Linux/macOS, khi `~/.local/bin` chưa có
  trong PATH, trình cài đặt in ra dòng `export PATH=...` để bạn thêm vào.
</Aside>

## Mở Termote trên điện thoại

<Steps>
1. Cho điện thoại truy cập được: `termote start --lan` trong mạng ở nhà, hoặc `termote start --tailscale <host>` để
   dùng HTTPS qua [Tailscale](/vi/installation/tailscale/), ra khỏi nhà vẫn vào được. Tùy chọn này được lưu cho lần
   khởi động sau.

2. Chạy `termote url --qr` (hoặc `termote panel`), quét mã QR bằng camera điện thoại, rồi đăng nhập bằng đúng tên và
   mật khẩu đó. Muốn điện thoại khỏi phải gõ mật khẩu thì [ghép nó](/vi/usage/devices/) bằng mã dùng một lần.

3. Thêm vào màn hình chính (Safari: **Share → Add to Home Screen**; Chrome: **Add to Home screen** hoặc
   **Install app**) để mở như một ứng dụng. Trên iPhone và iPad,
   [thông báo](/vi/usage/settings/#báo-khi-agent-cần-tôi) từ agent chỉ chạy trong ứng dụng ở màn hình chính.

4. Mở một pane đang chạy Claude Code hoặc Codex, rồi chuyển sang [Chat với agent](/vi/usage/agent-chat/) để đọc và
   trả lời.
</Steps>

## Cố định phiên bản hoặc sửa bản cài

Đặt `TERMOTE_VERSION` để cài đúng một bản phát hành (`X.Y.Z`, hoặc `X.Y.Z-rc.N` cho bản thử nghiệm):

<Tabs>
  <TabItem label="Linux / macOS">

    ```bash
    curl -fsSL https://termote.ohnice.app/install.sh | TERMOTE_VERSION=1.0.0 sh
    ```
  </TabItem>
  <TabItem label="Windows (PowerShell)">

    ```powershell
    $env:TERMOTE_VERSION='1.0.0'; irm https://termote.ohnice.app/install.ps1 | iex
    ```
  </TabItem>
</Tabs>

Khi không có `TERMOTE_VERSION`, trình cài đặt để nguyên bản cài hiện có và nhắc bạn chạy `termote update`. Khi
có biến này, nó đặt phiên bản đó cạnh bản hiện có rồi chuyển sang dùng nó. Đây cũng là cách cứu một bản cài
không còn chạy được. Cấu hình của bạn được giữ nguyên trong cả hai trường hợp.

`GH_TOKEN` hoặc `GITHUB_TOKEN`, nếu được đặt, chỉ nâng giới hạn gọi GitHub API mà trình cài đặt dùng để tìm bản
mới nhất.

## Bản thử nghiệm

Trình cài đặt, cũng như `termote update`, chỉ chọn bản thử nghiệm (`X.Y.Z-rc.N`) khi bạn ghi rõ nó trong
`TERMOTE_VERSION` (hoặc `termote update --version X.Y.Z-rc.N`). Không ghi thì bạn nhận bản ổn định mới nhất (từ 1.0 trở lên) **đã
phát hành**: một bản đang chờ phát hành đã có tag, nhưng chưa tải được tệp nào của nó. Bản thử nghiệm bạn ghi rõ cũng
vậy: khi nó chưa phát hành, quá trình cài báo lỗi `still publishing`.

Trang này phục vụ trình cài đặt của bản ổn định gần nhất. Muốn chạy chính trình cài đặt của một bản thử nghiệm, hãy
lấy nó từ tag của bản đó và vẫn ghi rõ phiên bản:

<Tabs>
  <TabItem label="Linux / macOS">

    ```bash
    curl -fsSL https://raw.githubusercontent.com/lamngockhuong/termote/v1.13.0-rc.1/scripts/install.sh | TERMOTE_VERSION=1.13.0-rc.1 sh
    ```
  </TabItem>
  <TabItem label="Windows (PowerShell)">

    ```powershell
    $env:TERMOTE_VERSION='1.13.0-rc.1'; irm https://raw.githubusercontent.com/lamngockhuong/termote/v1.13.0-rc.1/scripts/install.ps1 | iex
    ```
  </TabItem>
</Tabs>

Muốn quay về bản ổn định, chạy `termote update`. Khi bản `X.Y.Z` chính thức chưa ra, đây là một lần hạ phiên bản (bản
thử nghiệm được tính là mới hơn bản phát hành trước nó); `update` vẫn làm, kèm một cảnh báo.

<Aside type="caution" title="Chuyển từ Termote 0.x">
  Không có đường nâng cấp từ 0.x: bản 1.0 không đọc cấu hình hay bất cứ thứ gì 0.x để lại. Hãy gỡ 0.x trước
  theo trang lưu trữ [0.x native](/vi/0.x/installation/native/#gỡ-cài-đặt) hoặc
  [0.x container](/vi/0.x/installation/docker/#gỡ-cài-đặt), rồi cài 1.0 như trên.
</Aside>

## Các lệnh

Cờ có cùng cú pháp trên mọi hệ điều hành, kể cả PowerShell (`termote start --lan`).

| Lệnh                      | Chức năng                                                                     |
| ------------------------- | ----------------------------------------------------------------------------- |
| `termote start [options]` | Lưu các tùy chọn, đăng ký dịch vụ và khởi động nó                             |
| `termote stop`            | Dừng server (nó tự chạy lại ở lần đăng nhập sau)                              |
| `termote restart`         | Dừng rồi khởi động lại với các tùy chọn đã lưu                                |
| `termote status`          | Hiện thông tin server đang chạy báo về (tên khác: `health`)                   |
| `termote logs [service]`  | Xem log: `server`, `all` (mặc định), `follow`, `clean`                        |
| `termote show-password`   | Hiện tên đăng nhập và mật khẩu đã lưu                                         |
| `termote pair [options]`  | Tạo mã dùng một lần để đăng nhập thiết bị mới (`--role view\|full`, `--name`) |
| `termote devices`         | Liệt kê thiết bị đã ghép; `devices revoke <id>` đăng xuất một thiết bị        |
| `termote update`          | Cập nhật lên bản mới nhất, quay về bản cũ nếu bản mới không chạy được         |
| `termote uninstall`       | Gỡ dịch vụ, lệnh và bản cài (`--purge`: xóa cả cấu hình và log)               |
| `termote container <cmd>` | Chạy server trong container: `up`, `down`, `logs [-f]`, `status`             |
| `termote link` / `unlink` | Tạo hoặc xóa lệnh `termote` trong `~/.local/bin`                              |
| `termote version`         | Hiện phiên bản                                                                |
| `termote serve`           | Chạy server ngay trong terminal hiện tại (dịch vụ cũng chạy lệnh này)         |
| `termote`                 | Menu tương tác                                                                |

`termote help` in ra danh sách này kèm mọi tùy chọn. Lệnh cũ `install` đã bị bỏ: gõ nó thì chỉ nhận
lời nhắc dùng `termote start` và `termote container up`.

## Vị trí các file

| Nội dung        | Linux / macOS                                                  | Windows                                                    |
| --------------- | -------------------------------------------------------------- | ---------------------------------------------------------- |
| Thư mục cài     | `~/.local/share/termote` (`$XDG_DATA_HOME/termote`)            | `%LOCALAPPDATA%\termote`                                   |
| Các phiên bản   | `versions/<v>/bin/termote`                                     | `versions\<v>\bin\termote.exe`                             |
| Bản đang dùng   | liên kết `current` trỏ tới `versions/<v>`                      | `current.txt` cùng trình khởi chạy `bin\termote.cmd`       |
| Lệnh            | `~/.local/bin/termote`                                         | `%LOCALAPPDATA%\termote\bin`, được thêm vào PATH người dùng |
| Cấu hình        | `~/.config/termote/config` và `secret` (`$XDG_CONFIG_HOME`)    | `%APPDATA%\termote\config.json` (mật khẩu mã hóa bằng DPAPI) |
| Log, file PID   | `~/.local/state/termote/` (`$XDG_STATE_HOME`)                  | `%LOCALAPPDATA%\termote\state`                             |
