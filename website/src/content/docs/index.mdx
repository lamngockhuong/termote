Termote is an open-source (MIT), self-hosted web app that puts the terminal sessions of your machine on your phone or
another computer. One `termote` binary runs on Linux, macOS or Windows and serves a PWA that opens your tmux, Herdr or
Zellij (Linux, macOS) sessions over the network you choose: your LAN, Tailscale or a Cloudflare Tunnel, behind a password. From there
you can answer [Claude Code or Codex as a chat](/usage/agent-chat/), [switch sessions](/usage/sessions/), read a
pane's [files and git diff](/usage/files-changes/), and type with a [keyboard toolbar](/usage/keyboard/) made for
touch. See the [security model](/usage/security/) for what is exposed and how.

## Features

  <Card title="Session Switching" icon="rocket">
    Switch between tmux or Herdr sessions, tabs and panes instantly

  <Card title="PWA Ready" icon="puzzle">

  </Card>
  <Card title="Herdr Plugin" icon="laptop">

  </Card>
</CardGrid>

## Quick Install

```bash
curl -fsSL https://termote.ohnice.app/install.sh | sh      # Linux, macOS
termote start
```

```powershell
irm https://termote.ohnice.app/install.ps1 | iex           # Windows
termote start
```

## Deployment Modes

| Mode      | Command                | Use Case                          | Platform              |
| --------- | ---------------------- | --------------------------------- | --------------------- |
| Native    | `termote start`        | Host tool access (Claude Code)    | macOS, Linux, Windows |
| Container | `termote container up` | Isolated environment (Podman/Docker) | macOS, Linux, Windows |
