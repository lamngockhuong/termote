## Features

<CardGrid stagger>
  <Card title="Session Switching" icon="rocket">
    Switch between tmux or Herdr sessions, tabs and panes instantly
  </Card>
  <Card title="Agent Chat" icon="comment-alt">
    Read and answer Claude Code or Codex as a chat, with images and slash commands
  </Card>
  <Card title="Files and Changes" icon="document">
    Browse a pane's files and its git diff, with a Markdown preview
  </Card>
  <Card title="Mobile Optimized" icon="setting">
    Virtual keyboard toolbar with Tab, Esc, Ctrl, arrows
  </Card>
  <Card title="Gesture Support" icon="pencil">
    Swipe left for Ctrl+C, right for Tab, up/down to scroll
  </Card>
  <Card title="PWA Ready" icon="puzzle">
    Install to homescreen, works offline
  </Card>
  <Card title="Herdr Plugin" icon="laptop">
    Open the pane you are on in Termote, or show its link as a QR code
  </Card>
</CardGrid>

## Quick Install

```bash
curl -fsSL https://termote.ohnice.app/install.sh | sh      # Linux, macOS
termote start
```

```powershell
irm https://termote.ohnice.app/install.ps1 | iex           # Windows
termote start
```

## Deployment Modes

| Mode      | Command                | Use Case                          | Platform              |
| --------- | ---------------------- | --------------------------------- | --------------------- |
| Native    | `termote start`        | Host tool access (Claude Code)    | macOS, Linux, Windows |
| Container | `termote container up` | Isolated environment (Podman/Docker) | macOS, Linux, Windows |
