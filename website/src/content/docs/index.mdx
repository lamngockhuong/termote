Termote is an open-source (MIT), self-hosted web app that puts the terminal sessions of your machine on your phone or
another computer. One `termote` binary runs on Linux, macOS or Windows and serves a PWA that opens your tmux, Herdr or
Zellij (Linux, macOS) sessions over the network you choose: your LAN, Tailscale or a Cloudflare Tunnel, behind a password. From there
you can answer [Claude Code or Codex as a chat](/usage/agent-chat/), [switch sessions](/usage/sessions/), read a
pane's [files and git diff](/usage/files/), and type with a [keyboard toolbar](/usage/keyboard/) made for
touch. See the [security model](/usage/security/) for what is exposed and how.

## How It Works

<Steps>
1. **Install it on the machine that runs your agents.** One command on Linux, macOS or Windows, no sudo:
   see [Getting Started](/getting-started/).

2. **Make it reachable from your phone.** `termote start --lan` opens it to your home network;
   `termote start --tailscale <host>` serves it over HTTPS on your [tailnet](/installation/tailscale/), away
   from home too.

3. **Open it on your phone.** Scan the QR code that `termote panel` or `termote url --qr` shows, sign in, and
   add it to the home screen. Then answer Claude Code or Codex in [Agent Chat](/usage/agent-chat/).
</Steps>

## Is It Safe?

Termote is a remote shell: whoever signs in can do what your user can on that machine. Sign-in is on by
default, the server listens only on this machine until you pass `--lan`, and it refuses requests for host names
that are not on its allowlist. Prefer your LAN or Tailscale to opening it to the Internet, pair other devices
view-only, and read the [security model](/usage/security/) for what it protects and what it cannot.

## Quick Install

```bash
curl -fsSL https://termote.ohnice.app/install.sh | sh      # Linux, macOS
termote start
```

```powershell
irm https://termote.ohnice.app/install.ps1 | iex           # Windows
termote start
```

## Deployment Modes

| Mode      | Command                | Use Case                          | Platform              |
| --------- | ---------------------- | --------------------------------- | --------------------- |
| Native    | `termote start`        | Host tool access (Claude Code)    | macOS, Linux, Windows |
| Container | `termote container up` | Isolated environment (Podman/Docker) | macOS, Linux, Windows |
