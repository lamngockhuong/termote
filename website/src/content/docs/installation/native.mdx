No Docker required. Access host binaries like `claude`, `git`, `gh`, etc. termote streams
the terminal itself (PTY on Unix, ConPTY on Windows) into xterm.js in the PWA — there is no
separate terminal process to install.

## Prerequisites

<Tabs>
  <TabItem label="Linux">
    ```bash
    sudo apt install tmux
    ```
  </TabItem>
  <TabItem label="macOS">
    ```bash
    brew install tmux go
    ```
  </TabItem>
  <TabItem label="Windows">
    ```powershell
    # Install psmux (tmux-compatible for Windows)
    winget install psmux
    ```
  </TabItem>
</Tabs>

### tmux Configuration (Recommended)

For tmux copy/paste to work with the keyboard toolbar buttons, add this to your `~/.tmux.conf`:

```bash
# Vi mode for copy: Space=start selection, Enter=copy
set-option -g mode-keys vi
# Mouse support (scroll, select) - toggle with Ctrl+b m
set-option -g mouse on
bind m set -g mouse \; display "Mouse #{?mouse,on,off}"
```

Apply the config:

```bash
tmux source-file ~/.tmux.conf
```

This enables: **Copy icon** → navigate → **Space** → select → **Enter** → **Paste icon**

:::tip[Copy to System Clipboard]
With mouse ON, tmux captures mouse events. To copy to system clipboard:
- **Hold Shift** while selecting text (bypasses tmux, uses terminal selection)
- Or press **Ctrl+b m** to toggle mouse off temporarily
:::

## Installation

<Steps>
1. Install dependencies (see above)

2. Run deploy command

   <Tabs>
     <TabItem label="Unix (macOS/Linux)">
       ```bash
       ./scripts/termote.sh install native
       ```
     </TabItem>
     <TabItem label="Windows (PowerShell)">
       ```powershell
       .\scripts\termote.ps1 install native
       ```
     </TabItem>
   </Tabs>

3. Access at http://localhost:7680

</Steps>

## When to Use

- Need access to host binaries (claude, git, gh, etc.)
- No Docker/Podman available
- Full control over services
- Want the Herdr backend (native only, see below)

<Aside type="tip">
  Native mode is recommended when you need to use Claude Code or other host CLI
  tools.
</Aside>

## Herdr Backend

Native mode can drive Herdr workspaces instead of tmux. Herdr must already be running and
reachable on this host; Termote only talks to its socket.

<Tabs>
  <TabItem label="Unix (macOS/Linux)">
    ```bash
    ./scripts/termote.sh install native --mux herdr
    ```
  </TabItem>
  <TabItem label="Windows (PowerShell)">
    ```powershell
    .\scripts\termote.ps1 install native -Mux herdr
    ```
  </TabItem>
</Tabs>

<Aside type="caution" title="Herdr behavior differs from tmux">
  - Selecting a tab or pane on the PWA does **not** change what is shown on the Herdr desktop
  — it only changes which pane the client streams. There is no "show on desktop" button.
  - Each pane gets an agent-status badge (idle/working/blocked/done) refreshed at most once
  per the configured poll interval; it is not pushed instantly.
  - The Herdr backend is **native only** — `--mux herdr`/`-Mux herdr` is refused in container
  mode.
  - `--mux herdr --no-auth` is refused unless `--allow-herdr-no-auth` is also given: Herdr
  exposes every workspace on the host, not just the pane the PWA is showing, so running it
  without a password needs an explicit opt-in.
</Aside>

## Prevent macOS Sleep

macOS automatically sleeps after inactivity, disconnecting remote terminal sessions. Use `caffeinate` to keep the machine awake while Termote is running:

```bash
# Prevent system sleep (runs until you press Ctrl+C)
caffeinate -s

# Or run in background
caffeinate -s &

# Stop background caffeinate
pkill caffeinate
```

<Aside type="tip">
  Use `caffeinate -s` (system sleep only) instead of `-d` (display sleep) — you
  don't need the display on for remote access.
</Aside>

### Debug with Logs

<Tabs>
  <TabItem label="Unix (macOS/Linux)">

    ```bash
    termote logs follow     # Tail live (Ctrl+C to stop)
    termote logs clean      # Delete log files
    ```

  </TabItem>

    ```powershell
    .\scripts\termote.ps1 logs server     # Same, explicit
    .\scripts\termote.ps1 logs follow     # Tail all logs live (Ctrl+C to stop)
    .\scripts\termote.ps1 logs clean      # Delete log files
    ```
  </TabItem>
</Tabs>

### Common Issues

| Issue           | Solution                                          |
| --------------- | -------------------------------------------------- |
| Port in use     | `lsof -i :7680` (Unix) or `netstat -ano \| Select-String 7680` (Win) then kill process |
| Herdr not found | Install/start `herdr` first, or drop `--mux herdr` to use tmux |
| Binary missing  | `cd server && go build -o termote-dev .`    |
| PWA not built   | `pnpm --filter termote build`                            |
| Stale PWA cache | Settings → "Clear Cache & Reload" to refresh      |
| Host rejected (403) | Follow the `--allow-host <name>` suggested in the error, then reinstall |

## Updating

### Via CLI (Recommended)

If Termote is already installed, use the built-in update command:

<Tabs>
  <TabItem label="Unix (macOS/Linux)">
    ```bash
    termote update                   # Update to latest version
    termote update --version 1.0.0   # Pin to specific version
    termote update --force           # Force reinstall current version
    ```
  </TabItem>
  <TabItem label="Windows (PowerShell)">
    ```powershell
    .\scripts\termote.ps1 update                 # Update to latest version
    .\scripts\termote.ps1 update -Version 1.0.0  # Pin to specific version
    .\scripts\termote.ps1 update -Force          # Force reinstall current version
    ```
  </TabItem>
</Tabs>

This automatically preserves your config, stops services, downloads the new version, verifies
checksums, and re-installs with your saved settings. Upgrading a 0.x install to 1.0.0 also
drops ttyd and migrates an empty saved password — see `docs/upgrade-1.0.md` in the repository
for the full breaking-change list.

### Via One-liner

Re-run the installer - it compares versions and prompts before updating:

<Tabs>
  <TabItem label="Unix (macOS/Linux)">
    ```bash
    # Auto-update with saved config
    curl -fsSL https://raw.githubusercontent.com/lamngockhuong/termote/main/scripts/get.sh | bash -s -- --update

    # Or standard update
    curl -fsSL https://raw.githubusercontent.com/lamngockhuong/termote/main/scripts/get.sh | bash
    ```

    Options: `--update`, `--yes`, `--download-only`, `--fresh`, `--version <ver>`, `--strict`
  </TabItem>
  <TabItem label="Windows (PowerShell)">
    ```powershell
    # Auto-update with saved config
    $env:TERMOTE_UPDATE="true"; irm https://raw.githubusercontent.com/lamngockhuong/termote/main/scripts/get.ps1 | iex

    # Or standard update
    irm https://raw.githubusercontent.com/lamngockhuong/termote/main/scripts/get.ps1 | iex
    ```

    Options: `$env:TERMOTE_UPDATE="true"`, `$env:TERMOTE_AUTO_YES="true"`
  </TabItem>
</Tabs>
